# AI Appointment Setter (Next.js 16 + Tailwind 4 + Supabase)

A modern appointment setter demo with plan-based AI gating:

- **Starter**: AI and voice disabled.
- **Voice Pro**: Voice enabled, AI disabled.
- **AI Agent**: Voice and AI enabled.

## Features

- Next.js 16 App Router.
- Tailwind CSS v4 styling.
- Framer Motion animations for cards and state transitions.
- Voice booking input using browser SpeechRecognition API.
- Supabase-backed availability endpoint (`appointment_slots` table).
- Fallback mock data when Supabase env vars are missing.

## Supabase schema

```sql
create table if not exists appointment_slots (
  id bigint generated by default as identity primary key,
  date date not null,
  time text not null,
  is_booked boolean default false
);
```

## Run

```bash
npm install
npm run dev
```

Create `.env.local` from `.env.example` and set Supabase credentials.
